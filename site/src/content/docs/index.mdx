## What it does

An agent such as Claude Code, Pi or Codex runs `niri-computer-use serve` and gets five read-only tools, six when Noctalia is installed: the windows and workspaces, the monitor layout, screenshots, the clipboard's text, Noctalia's panels, and a readiness report. It can't click, type or launch anything yet.

## How it differs from a screenshot tool

- **Structured state first.** Windows, workspaces and focus come from niri's own event stream, so the agent reads them instead of guessing from pixels.
- **Screenshots that map back to the layout.** Every screenshot says which output and rectangle it shows and at what scale, and its size is checked against the image itself.
- **Small text without huge images.** Screenshots default to 1280 pixels wide; a region screenshot reads small text at the output's own scale.
- **An audit log without contents.** Each call is logged with its arguments and outcome, never the clipboard text, window titles or image data.
- **No root, no uinput.** It talks to niri, grim, `wl-paste` and logind as your user.

## Install

From a shell inside your niri session:

```sh
git clone https://github.com/ayagmar/niri-computer-use.git
cargo install --locked --path niri-computer-use
claude mcp add --scope user niri-computer-use -- ~/.cargo/bin/niri-computer-use serve
```

Pi and Codex are covered in [Getting started](guides/getting-started/).
