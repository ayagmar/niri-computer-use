## Plan changes

Found during M0 and applied to the plan as revision 9.

1. **§13 stage 4: niri doesn't exit when the supervisor does.** niri double-forks its `--` command and doesn't wait for it (`src/utils/spawning.rs`, `do_spawn`, at `v26.04`). The supervisor now sends `Quit` to the nested niri once its socket has been checked. niri also starts that command with stdin, stdout and stderr set to null (`spawning.rs`, `spawn_sync`), so the supervisor reports through files.
2. **§13 stage 1: the private bus socket lands in the host `/tmp`.** The default session config listens with `unix:tmpdir=/tmp`. The harness gives `dbus-run-session` its own config, which listens in `TEST_DIR/run` and has no service directories. This is also what makes the kickoff's "`DBUS_SESSION_BUS_ADDRESS` points into `TEST_DIR`" check possible.
3. **§13 stage 0: the containment rule and the kept variables contradict each other.** "Every path variable must resolve under `TEST_DIR`" can't hold for `HOME` and `PATH`, which the same stage keeps. The harness applies containment to the XDG and Noctalia directories, exempts `WAYLAND_DISPLAY`, keeps `HOME`, `PATH` and `LANG` as they are, and rejects any other variable.
