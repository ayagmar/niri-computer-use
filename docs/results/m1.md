## Other observations

- **Lock state while locked.** On 2026-10-08 the screen was locked during a run. `status` reported `{"state": "locked", "source": "logind", "logind_error": null}`; `loginctl show-session 3 -p LockedHint` said `yes` and Noctalia's `status` reply had `locked: true`.
- **The default `max_width`.** Plan §4 kept 1280 provisional until this check. At 1280 the screenshot showed the layout, and the model took a region screenshot to read terminal text, as the skill says. 1280 stays the default.
- **Client environments.** The Inspector and Codex give a stdio server a minimal environment, without `NIRI_SOCKET`; Claude Code and Pi pass theirs on. The Inspector script and Codex's `env_vars` setting forward the four variables the server needs.
- **Protocol checks.** `tests/protocol/` drives the server over stdio against fakes, in `make check` and CI: 38 tests covering the handshake, both error shapes, cancellation with process-group cleanup, deadlines, concurrent calls, event-stream reconnects and malformed events, Noctalia's three states, the lock sources, the clipboard and the audit log.
