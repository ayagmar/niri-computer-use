# M5 results

Acceptance evidence for milestone M5, the Noctalia integration: `shell_open` and `shell_close` with the panel allowlist, Noctalia as the lock state's fallback source, C13 moved onto the server's tools, and the optional OCR helper. Nested runs keep their files in `target/e2e/<run>/`, which isn't committed.

Machine: niri 26.04 (8ed0da4), Noctalia 5.2.1, Rust 1.99.0. tesseract was installed only for the last OCR run.

No command went to the host's Noctalia: every panel command went to the nested Noctalia, whose socket the harness checked to resolve under `TEST_DIR/run` before each call. No input was sent to the real session.

## Other observations

- **The OCR helper.** It looks for `Home`, the open control center's title, with `grim -s 2` and `tesseract --psm 11`. tesseract wasn't installed for the runs above, so they logged "OCR: skipped, tesseract is not on PATH". After installing tesseract 5.5.3 with English data, `make nested NOCTALIA=1` at scale 1 (run 1791511759-4132253) logged "OCR: found "Home"" and passed.
- **The nested wallpaper panel.** With Noctalia's default, the wallpaper panel lists the pictures directory of the user whose `HOME` the nested session keeps. The generated config now points it at an empty directory in `TEST_DIR`.
- **Review findings fixed in this milestone.** A timeout before any status read answered reported no open panel instead of an unknown one; C13's two seconds were logged but not checked; the skill gave the shell tools the five-second wait of niri's actions.
