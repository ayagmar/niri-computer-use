## Findings

- Codex's `env_vars` in the old README and getting-started page lacked `DBUS_SESSION_BUS_ADDRESS`, so a Codex agent never saw `elements`. It listed `XDG_SESSION_ID`, which the server doesn't read: it finds niri's own session through niri's socket. The Inspector confirmed both: 22 tools without the bus variable, 23 with it, and the lock state from logind without `XDG_SESSION_ID`.
- `codex mcp list` doesn't start the server, so it can't confirm a connection.
- The MCP Inspector 2.9.0's `--cli <command>` form answered `No servers found in config file`; only `--config` with `--server` worked, so the site documents that form.
- Starlight's splash hero crops its image to 400×400, which cut the still to its middle; the still sits in the page body instead.
- GitHub private vulnerability reporting is off for the repository. `SECURITY.md` points to it, so it has to be turned on before this branch is merged.
