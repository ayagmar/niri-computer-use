## Other observations

- **The server's event times.** The M0 probe chose its own event times, and the checks read only events with them. The server's pointer uses the monotonic clock, so the checks read `wev`'s log after an offset taken before each call instead; a host pointer crossing the nested window could fail a check but never pass one.
- **niri reports no position for tiled windows.** `tile_pos_in_workspace_view` is null for kitty tiled in the scrolling layout, so the nested config floats kitty at a fixed size, as it already does `wev`.
- **kitty's blank cursor line.** After `seq`, kitty's last screen line is the empty cursor line, so the bottom number moved by one less than the scroll; the check reads the top line, which moves by exactly the lines scrolled.
- **Review findings fixed in this milestone.** A gesture cancelled midway removed its marker after a flush rather than after niri handled the release; a failure before any input was reported `uncertain`; wtype's stdin decoding depends on the locale, so wtype now runs in `C.UTF-8`; a wtype that exits before reading no longer leaves the marker. The protocol tests drive the keyboard path through a fake wtype.
